# 事前アンケート 質問案（Google フォーム用）

目的：グループで学ぶ場合に、受講者のレベルと環境を、学習を始める前に把握する（一人で学ぶ場合は不要）。所要時間は5分程度。
作り方は、末尾の「フォームの作り方」を参照。

## フォームの説明文（先頭に貼る）

> これは「Git と GitHub 入門」を始める前の、事前アンケートです。
> テストではありません。「できない」「知らない」と答えても、まったく問題ありません。
> 今の状況に合わせて教材を調整するために使います。所要時間は5分ほどです。

## セクション1：あなたについて

**Q1. ニックネーム（教材の中で使う名前）**
- 形式：記述式（短文）／必須
- 補足：本名でなくて構いません。

**Q2. 使っているパソコンについて（当てはまるものをすべて選択）**
- 形式：チェックボックス／必須
- 選択肢
  - Windows 11 のパソコンを使っている
  - 自分で管理しているパソコンである（ソフトを自由に入れられる）
  - 会社や学校のパソコンである（ソフトのインストールに許可が必要）
  - よく分からない

## セクション2：パソコンの操作

**Q3. 普段できることを選んでください（当てはまるものをすべて選択）**
- 形式：チェックボックス／必須
- 選択肢
  - エクスプローラーでフォルダを作り、ファイルを整理できる
  - ファイルのコピー、貼り付け、名前の変更ができる
  - ZIP ファイルを作る、または展開できる
  - 新しいアプリをインストールできる
  - ファイル名の拡張子（.txt など）を、表示して確認できる
  - ショートカットキー（Ctrl+C、Ctrl+V など）を使っている
  - どれも自信がない

**Q4. 日本語入力（IME）の、半角英数と日本語の切り替えができますか？**
- 形式：ラジオボタン／必須
- 選択肢
  - 半角/全角キーなどで、自由に切り替えられる
  - 切り替えられるが、今どちらか分からなくなることがある
  - 切り替え方が分からない

**Q5. キーボードの種類**
- 形式：ラジオボタン／必須
- 選択肢
  - 日本語キーボード（半角/全角キーがある）
  - 英語キーボード
  - ノートパソコンの内蔵キーボード（種類は分からない）
  - 分からない

**Q6. OneDrive について**
- 形式：ラジオボタン／必須
- 選択肢
  - デスクトップやドキュメントを、OneDrive でバックアップしている
  - OneDrive は使っていない
  - 分からない

## セクション3：これまでの経験

**Q7. ターミナル（PowerShell、コマンドプロンプトなど、黒や青の画面）の経験**
- 形式：ラジオボタン／必須
- 選択肢
  - 聞いたことがない
  - 名前は聞いたことがあるが、使ったことはない
  - 手順書の通りに、コマンドを打ったことがある
  - 自分でコマンドを選んで、使うことがある

**Q8. プログラミングの経験**
- 形式：ラジオボタン／必須
- 選択肢
  - まったくない
  - 少し触ったことがある（授業、体験など）
  - 自分で、簡単なものを作ったことがある
  - 仕事や趣味で、日常的に書いている

**Q9. Git と GitHub について（当てはまるものをすべて選択）**
- 形式：チェックボックス／必須
- 選択肢
  - 聞いたことがない
  - 名前は知っている
  - GitHub のアカウントを持っている
  - commit や push をしたことがある
  - ブランチや Pull Request を使ったことがある

**Q10. 他の人と、同じファイルを共同で扱った経験（当てはまるものをすべて選択）**
- 形式：チェックボックス／必須
- 選択肢
  - 共有フォルダ（Teams、Google ドライブなど）で、同じファイルを編集したことがある
  - 同じファイルを、複数人で別々に編集して、あとから合わせたことがある
  - ファイルの古い版に、戻したくなったことがある
  - 特にない

## セクション4：学習について

**Q11. 学習に使えそうな時間（自習）**
- 形式：ラジオボタン／必須
- 選択肢
  - 週に1時間未満
  - 週に1〜2時間
  - 週に3時間以上
  - 決まっていない

**Q12. 集まり（ディスカッション）に、参加できそうですか？**
- 形式：ラジオボタン／必須
- 選択肢
  - 毎回参加できそう
  - 参加できない月もありそう
  - 難しそう

**Q13. 共同開発や、この教材に期待していること、不安なこと（自由記述）**
- 形式：記述式（長文）／任意

## フォームの作り方（Google フォーム）

1. https://forms.google.com を開き、「空白のフォーム」を作る。
2. タイトルは「Git と GitHub 入門 事前アンケート」にして、上の説明文を貼る。
3. セクション1〜4を作り、質問を上の通りに入力する（必須／任意も合わせる）。
4. 「設定」→「回答」で、**「メールアドレスを収集する」はオフ**にする（ニックネームで識別するため）。
5. 「設定」→「回答」で、「回答者に、回答のコピーを送信」は不要。「1回の回答に制限」は、ログインが必要になるのでオフにする。
6. 「回答」タブ → 「スプレッドシートにリンク」で、回答が表で見られるようにする。
7. 右上の「送信」→ リンクのアイコンから、回答用の URL（`https://forms.gle/…`）をコピーする。
8. その URL を教えてもらえれば、第0章に「最初にアンケートに答える」の節を追加する。

## 結果の見方（レベルの目安）

| 項目 | 集計のポイント |
|---|---|
| Q3, Q4, Q5 | ファイル操作・入力切替の習熟度。Q4 が「分からない」なら、第0章・第2章で入力モードの確認を丁寧に行う |
| Q6 | OneDrive でバックアップが有効なら、第1章の「学習用フォルダ」の説明を重視する |
| Q7, Q8 | ターミナル・プログラミングの経験。全員「ない」なら、第2章は現在の構成のまま進める |
| Q9, Q10 | Git の経験の差。差が大きければ、集まりで、経験者が説明役になる進め方を検討する |
| Q11, Q12 | 学習時間と参加可否。全員で足並みをそろえる進度の目安にする |
