# Claude in Chrome 用プロンプト（事前アンケートの Google フォームを作る）

> **【終了】この事前アンケートは、2026-10-31 に終了しました。** 回答の受け付けは停止しています。このファイルは、作成時の記録として残しています（新しく使う予定はありません）。

`survey/questions.md` の質問案を、Chrome の Claude 拡張機能に Google フォームとして作ってもらうためのプロンプトです。

## 使い方

1. Chrome で、教材を管理している Google アカウントにログインしておく。
2. Claude 拡張機能のサイドパネルを開く。
3. 下の「プロンプト本文」の枠の中を、すべてコピーして貼り付け、送信する。
4. 作業の途中で拡張機能が許可を求めたら、内容を確認して許可する。
5. 完成したら、報告された「回答用 URL」を教材の第0章（0-5）に載せる。

質問の中身を変えたいときは、先に `survey/questions.md` を直し、このファイルのプロンプト本文も同じように直す。

## プロンプト本文

````text
Google フォームで、プログラミング初心者向け教材「Git と GitHub 入門」の事前アンケートを作ってください。
学ぶ人のレベルと環境を、学習を始める前に把握するためのものです（一人で学ぶ人も、仲間と学ぶ人も対象）。

# 進め方
- 新しいタブで https://forms.google.com を開き、「空白のフォーム」から作成してください。
- 下の「フォームの内容」の文言は、一字一句そのまま入力してください（言い換え・要約・選択肢の並べ替えはしない）。
- 質問の形式は、Google フォームの次の種類を使ってください。
  - 「記述式（短文）」→ 記述式
  - 「記述式（長文）」→ 段落
  - 「ラジオボタン」→ ラジオボタン
  - 「チェックボックス」→ チェックボックス
- 「必須」の質問は、右下の「必須」スイッチをオンにしてください。「任意」はオフのままです。
- 「補足」がある質問は、質問の右下の「︙」→「説明」を表示して、その欄に入力してください。
- セクション1の内容は、最初のセクション（フォームのタイトルがある部分）に入れてください。セクション2〜4は、右側のツールバーの「セクションを追加」で作り、セクションのタイトルを入力してください。
- 「その他」の選択肢は追加しないでください。選択肢は書かれたものだけです。
- 1問入力するごとに、質問文・形式・選択肢・必須が合っているか確認してから、次に進んでください。
- 次のことはしないでください：フォームを誰かにメールで送る、共同編集者を追加する、テーマやデザインを変える、既存のフォームやファイルを削除・変更する。
- 迷ったこと、うまく操作できなかったことがあれば、自己判断で別のやり方にせず、作業を止めて私に聞いてください。

# フォームの内容

## フォームのタイトル
Git と GitHub 入門 事前アンケート

## フォームの説明
これは「Git と GitHub 入門」を始める前の、事前アンケートです。
テストではありません。「できない」「知らない」と答えても、まったく問題ありません。
今の状況に合わせて教材を調整するために使います。所要時間は5分ほどです。

## セクション1：あなたについて
（このセクションは、フォームのタイトルがある最初のセクションに入れる）

Q1. ニックネーム（教材の中で使う名前）
- 形式：記述式（短文）／必須
- 補足：本名でなくて構いません。

Q2. 使っているパソコンについて（当てはまるものをすべて選択）
- 形式：チェックボックス／必須
- 選択肢：
  - Windows 11 のパソコンを使っている
  - 自分で管理しているパソコンである（ソフトを自由に入れられる）
  - 会社や学校のパソコンである（ソフトのインストールに許可が必要）
  - よく分からない

## セクション2：パソコンの操作

Q3. 普段できることを選んでください（当てはまるものをすべて選択）
- 形式：チェックボックス／必須
- 選択肢：
  - エクスプローラーでフォルダを作り、ファイルを整理できる
  - ファイルのコピー、貼り付け、名前の変更ができる
  - ZIP ファイルを作る、または展開できる
  - 新しいアプリをインストールできる
  - ファイル名の拡張子（.txt など）を、表示して確認できる
  - ショートカットキー（Ctrl+C、Ctrl+V など）を使っている
  - どれも自信がない

Q4. 日本語入力（IME）の、半角英数と日本語の切り替えができますか？
- 形式：ラジオボタン／必須
- 選択肢：
  - 半角/全角キーなどで、自由に切り替えられる
  - 切り替えられるが、今どちらか分からなくなることがある
  - 切り替え方が分からない

Q5. キーボードの種類
- 形式：ラジオボタン／必須
- 選択肢：
  - 日本語キーボード（半角/全角キーがある）
  - 英語キーボード
  - ノートパソコンの内蔵キーボード（種類は分からない）
  - 分からない

Q6. OneDrive について
- 形式：ラジオボタン／必須
- 選択肢：
  - デスクトップやドキュメントを、OneDrive でバックアップしている
  - OneDrive は使っていない
  - 分からない

## セクション3：これまでの経験

Q7. ターミナル（PowerShell、コマンドプロンプトなど、黒や青の画面）の経験
- 形式：ラジオボタン／必須
- 選択肢：
  - 聞いたことがない
  - 名前は聞いたことがあるが、使ったことはない
  - 手順書の通りに、コマンドを打ったことがある
  - 自分でコマンドを選んで、使うことがある

Q8. プログラミングの経験
- 形式：ラジオボタン／必須
- 選択肢：
  - まったくない
  - 少し触ったことがある（授業、体験など）
  - 自分で、簡単なものを作ったことがある
  - 仕事や趣味で、日常的に書いている

Q9. Git と GitHub について（当てはまるものをすべて選択）
- 形式：チェックボックス／必須
- 選択肢：
  - 聞いたことがない
  - 名前は知っている
  - GitHub のアカウントを持っている
  - commit や push をしたことがある
  - ブランチや Pull Request を使ったことがある

Q10. 他の人と、同じファイルを共同で扱った経験（当てはまるものをすべて選択）
- 形式：チェックボックス／必須
- 選択肢：
  - 共有フォルダ（Teams、Google ドライブなど）で、同じファイルを編集したことがある
  - 同じファイルを、複数人で別々に編集して、あとから合わせたことがある
  - ファイルの古い版に、戻したくなったことがある
  - 特にない

## セクション4：学習について

Q11. 学習に使えそうな時間（自習）
- 形式：ラジオボタン／必須
- 選択肢：
  - 週に1時間未満
  - 週に1〜2時間
  - 週に3時間以上
  - 決まっていない

Q12. （仲間と一緒に学ぶ場合）集まり（ディスカッション）に、参加できそうですか？
- 形式：ラジオボタン／必須
- 選択肢：
  - 一人で学ぶので、当てはまらない
  - 毎回参加できそう
  - 参加できないときもありそう
  - 難しそう

Q13. Git や GitHub、この教材に期待していること、不安なこと（自由記述）
- 形式：記述式（長文）／任意

# 設定（「設定」タブ →「回答」）
- 「メールアドレスを収集する」：収集しない（ニックネームで識別するため）
- 「回答のコピーを回答者に送信」：オフ
- 「1回の回答に制限する」：オフ（回答者にログインを求めないため）
- 上記以外の設定は変更しないでください。

# 回答をスプレッドシートで見られるようにする
「回答」タブ →「スプレッドシートにリンク」→「新しいスプレッドシートを作成」で、名前は「Git と GitHub 入門 事前アンケート（回答）」にしてください。

# 最後の確認
1. 右上の「プレビュー」（目のアイコン）で回答画面を開き、次を確認してください。
   - セクションが4つあり、「次へ」で順に進めること
   - 質問が Q1〜Q13 の13問で、順番・形式・選択肢が上の通りであること
   - Q13 以外の12問に、必須の「*」が付いていること
   - プレビューでは、回答を送信しないでください。
2. 右上の「送信」→ リンクのアイコン →「URL を短縮」にチェックを入れて、回答用 URL（https://forms.gle/… の形）を表示してください。ここでもメール送信はしないでください。

# 報告してほしいこと

- 回答用 URL（https://forms.gle/…）
- 回答のスプレッドシートの URL
- 上の「最後の確認」の結果（問題があれば、どの質問のどこが違うか）
````
