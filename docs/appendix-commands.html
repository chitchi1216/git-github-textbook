付録A

よく使うコマンド一覧

この一覧の使い方 教材に出てきたコマンドを、1か所にまとめた早見表です。忘れたときに見返してください。章が進むたびに、新しいコマンドが増えていきます。
「章」の列は、そのコマンドが最初に出てくる章です。リンクから、くわしい説明に戻れます。
打つときの約束 入力は半角英数で。コマンドと、そのあとの文字の間は半角スペースを1つ入れます。フォルダ名 などの日本語の部分は、自分の名前に置き換えます。

cd C:\workchange directory（絶対パスで指定）学習用フォルダへ移動する（どこからでも使える）cd C:\work第2章

A-5. Git の設定

コマンドもとの英語意味使用例章
git config --global user.nameconfig ＝ configuration（設定）自分の名前を登録するgit config --global user.name "あなたの名前"第0章
git config --global user.emailconfig ＝ configuration（設定）自分のメールアドレスを登録するgit config --global user.email "メールアドレス"第0章
git config --global core.editorconfig ＝ configuration（設定）Git が使うエディタを、メモ帳にするgit config --global core.editor notepad第0章
git config --global --listconfig ＝ configuration（設定）、list（一覧）登録した設定を確認するgit config --global --list第0章
git config --global init.defaultBranchconfig ＝ configuration（設定）、branch（枝）最初の枝の名前を、main にする（一度だけ）git config --global init.defaultBranch main第3章
git config --global pull.rebase falseconfig ＝ configuration（設定）、rebase（別の方法）git pull で、GitHub の変更を「合わせる（merge）」方法に決める（一度だけ）git config --global pull.rebase false第4章

第3章〜第6章のコマンドを載せています。第7章以降も、順番に追加していきます。

コマンドもとの英語意味使用例章

git statusstatus（状態）今の状態を表示する。迷ったら、まずこれgit status第3章
git addadd（追加する）変更を、ステージに並べるgit add hello.txt第3章
git commit -mcommit（確定する）、messageステージの変更を、メッセージ付きで記録するgit commit -m "Add hello.txt"第3章
git loglog（記録）履歴を表示する（画面が止まったら q）git log第3章
git log --onelineoneline（1行）履歴を、1つ1行で表示するgit log --oneline第3章
git log --grepgrep（文字を探す）メッセージの中から、文字を探すgit log --oneline --grep=second第3章

git remote add originremote（離れた）、add（追加）、origin（もと）GitHub のリポジトリを、origin という名前で登録するgit remote add origin https://github.com/ユーザー名/my-notes.git第4章
git remote -vverbose（くわしく）登録したリモートの URL を表示するgit remote -v第4章
git push -u origin mainpush（押し出す）、upstream（上流）初めて GitHub に送る。以降は git push だけで済むgit push -u origin main第4章
git pushpush（押し出す）自分の記録を、GitHub に送るgit push第4章
git pullpull（引っ張る）GitHub の記録を、自分のパソコンに受け取る（fetch ＋ merge）git pull第4章
git fetchfetch（取ってくる）GitHub の最新情報を取ってくるだけ。手元のファイルは変わらないgit fetch第4章
git cloneclone（複製）GitHub のリポジトリを、履歴ごと、まるごと複製するgit clone https://github.com/ユーザー名/my-notes.git my-notes-copy第4章
git showshow（見せる）1つの記録の中身（誰が・いつ・何を変えたか）を表示するgit show 6e467d8第5章

git restore --stagedstaged（ステージに並べられた）ステージから下ろす（add を取り消す）。ファイルの中身は変わらないgit restore --staged diary.txt第5章
git revertrevert（元の状態に戻す）記録を打ち消す、新しい記録を作る。push したあとでも安全git revert 49d72cc第5章

git branchbranch（枝）ブランチの一覧を表示する。* が、今いる枝git branch第6章

git switch -ccreate（作る）ブランチを作って、そこへ切り替えるgit switch -c add-notes第6章

git mergemerge（合流させる）別のブランチを、今いるブランチに合流させるgit merge add-notes第6章
