0-1. 登場するものを先に知る

名前一言でいうと
Gitファイルの変更履歴を記録する道具。自分のパソコンの中で動く
GitHubGit の記録をインターネット上に置いて、みんなで共有するサービス
VS Code文章やプログラムを書くための高機能なメモ帳（エディタ）

「Git」と「GitHub」は名前が似ていますが、別のものです。次の図で関係をつかんでください。

0-2. GitHub アカウントを作る

  1. ブラウザで https://github.com/signup を開く
  2. メールアドレス、パスワード、ユーザー名を入力する
  3. メールに届く確認コードを入力する
ユーザー名は他のメンバーにも見られます ユーザー名は共同開発で他のメンバーにも表示されます。本名でなくてもよいので、チームの中で誰か分かる名前にしてください。
パスワードは使い回さない 他のサービスと同じパスワードにしないでください。パスワード管理アプリの利用もおすすめです。

登録できると、自分のページ（プロフィール）ができます。ユーザー名が chitchi1216 なら、https://github.com/chitchi1216 が自分のページです。

0-3. Git をインストールする

  1. https://git-scm.com/download/win を開き、64-bit 版のインストーラーをダウンロードする
  2. ダウンロードしたファイルを開き、基本的に すべて初期設定のまま「Next」 を押して進める
  3. 最後に「Install」→「Finish」

0-4. VS Code をインストールする

  1. https://code.visualstudio.com/ からダウンロードする
  2. インストール中に「PATH への追加」にチェックが入っていることを確認する
  3. インストールできたら、スタートメニューから「Visual Studio Code」を起動する

0-5. 「自分は誰か」を Git に教える

Git は変更を記録するとき、誰が変更したかも一緒に記録します。そのため、最初に名前とメールアドレスを登録します。

ここで初めて、ターミナルを使います。詳しい説明は第2章で行うので、今は「書かれた通りに打つ」だけで大丈夫です。

  1. キーボードの Windows キーを押し、「PowerShell」と入力して Enter を押す
  2. 青か黒の画面が開く。これがターミナルです

次の2行を1行ずつ入力して Enter を押します（「" "」の中は自分の名前とメールアドレスに置き換える）。

git config --global user.name "あなたの名前"
git config --global user.email "GitHubに登録したメールアドレス"

何も表示されなければ成功です。続けて、設定を確認します。

git config --global --list

次のように、入力した名前とメールアドレスが表示されれば完了です（表示のイメージ）。

うまくいかないとき git : 用語 'git' は、コマンドレット…として認識されません と表示されたら、Git が見つかっていません。PowerShell をいったん閉じて開き直してからもう一度試してください。それでもだめなら、月1回の集まりかチャットで質問してください。

確認クイズ

Q1. Git と GitHub の違いは何ですか？

Git は変更履歴を記録する道具で、自分のパソコンの中で動く。GitHub は、その記録をインターネット上に置いて共有するサービス。

Q2. なぜ最初に名前とメールアドレスを登録するのですか？

Git が変更を記録するとき、誰が変更したかも一緒に記録するため。
