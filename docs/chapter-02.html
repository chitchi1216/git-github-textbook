ターミナル入門

この章でできるようになること
  • ターミナルが何かを、エクスプローラーと比べて説明できる
  • 「今いる場所」を確認し、フォルダを移動できる
  • フォルダとファイルを、コマンドで作れる

2-1. ターミナルとは

ターミナルは、パソコンに文字で指示を出す画面です。エクスプローラーは、マウスでクリックして指示を出します。ターミナルは、キーボードで「コマンド」という短い命令を打って指示を出します。操作する相手は、どちらも同じファイルとフォルダです。

なぜ、わざわざ文字で操作するの？ Git は、コマンドを打って使う道具だからです。「何をしたか」が文字で残るので、手順を人に伝えたり、同じ操作を正確に繰り返したりしやすくなります。難しいものではなく、「同じことを、別の言い方でお願いしているだけ」と考えてください。

この教材では、PowerShell（パワーシェル）というターミナルを使います。Windows 11 に最初から入っています。

2-2. エクスプローラーの操作とコマンドを見比べる

次の表は、「やりたいこと」を、エクスプローラーとターミナルで比べたものです。まずは眺めて、「あの操作の、文字での言い方だな」と対応づけてください。

やりたいことエクスプローラーPowerShell（コマンド）
今いる場所を知るアドレスバーを見るpwd
中身を一覧で見るフォルダを開くと、自然に表示されるls
フォルダの中に入るフォルダをダブルクリックcd フォルダ名
ひとつ上のフォルダに戻る「↑」ボタンを押すcd ..
自分のユーザーフォルダに戻るアドレスバーに C:\Users\自分の名前 と入力cd ~
新しいフォルダを作る右クリック → 新規作成 → フォルダーmkdir フォルダ名
空のテキストファイルを作る右クリック → 新規作成 → テキスト ドキュメントNew-Item ファイル名.txt
ファイルの中身を見るダブルクリックで、アプリで開くcat ファイル名.txt
今のフォルダをエクスプローラーで開く（もともとエクスプローラーなので不要）explorer .
今のフォルダを VS Code で開くフォルダを右クリック → 「Code で開く」code .
画面をきれいにする—cls

表にある .（ドット1つ）は「今いるフォルダ」、..（ドット2つ）は「ひとつ上のフォルダ」を表す、特別な書き方です。

同じ操作を、2つの画面で並べてみる

C:\Users\taro\practice というフォルダを開いている状態を、2つの画面で並べると、次のように対応します。

2-3. 「現在地」を意識する

ターミナルで一番大切なのは、「今、どのフォルダにいるか」です。エクスプローラーでは、開いているフォルダが画面に見えているので、意識しなくても分かります。ターミナルでは、文字でしか分かりません。

現在地は、行の先頭に表示されます。この部分をプロンプトといいます。

PS C:\Users\taro> ← ここが現在地（C:\Users\taro にいる）

コマンドは、今いるフォルダに対して実行されます。たとえば mkdir practice は、今いるフォルダの中に practice フォルダを作ります。「どこにいるか分からなくなった」ときは、pwd を打てば確認できます。

2-4. 実際にやってみよう

次の手順で、practice フォルダを作り、その中にファイルを作ります。ここで作る practice フォルダは、第3章以降でも使います。

打つ前に確認 入力モードを「半角英数」にしてください（第0章を参照）。コマンドと、その後ろの文字の間は半角スペースを1つ入れます。cd.. のようにスペースがないと動きません。

手順1：PowerShell を開き、今いる場所を確認する

Windows キーを押し、「PowerShell」と入力して Enter。開いたら、次のコマンドを打って Enter を押します。

pwd
PS C:\Users\taro> pwd

Path
----
C:\Users\taro

C:\Users\自分の名前 と表示されれば OK です（taro の部分は、人によって違います）。

手順2：中身を見る

ls

今いるフォルダの中の、フォルダとファイルの一覧が出ます。エクスプローラーで同じフォルダを開いた時の中身と、見比べてみてください。

手順3：フォルダを作る

mkdir practice
PS C:\Users\taro> mkdir practice

    Directory: C:\Users\taro

Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
d-----        2026/10/11     10:30                practice

表示のイメージです。日付や時刻は、人によって違います。

手順4：フォルダの中に入る

cd practice
PS C:\Users\taro> cd practice
PS C:\Users\taro\practice>

プロンプトが C:\Users\taro\practice に変わりました。現在地が移動した合図です。

手順5：ファイルを作る

New-Item memo.txt
PS C:\Users\taro\practice> New-Item memo.txt

    Directory: C:\Users\taro\practice

Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
-a----        2026/10/11     10:31              0 memo.txt

Length が 0 なのは、中身が空のファイルだからです。

手順6：エクスプローラーで確かめる

explorer .

最後の .（ドット）を忘れないでください。エクスプローラーが開き、practice フォルダの中に memo.txt があるはずです。ターミナルで作ったものが、エクスプローラーにも見えることを確認してください。

手順7：VS Code で開く

code .

VS Code が起動し、practice フォルダが開きます。memo.txt に hello と書いて、保存してください（Ctrl + S）。

ここでは英語（半角）で書く Windows PowerShell では、日本語を含む文字ファイルを cat で表示すると、文字化けすることがあります。ファイルが壊れたわけではなく、表示の問題です。今回は半角の英語（hello）で試してください。

手順8：中身をターミナルで見て、元の場所へ戻る

cat memo.txt
cd ..
PS C:\Users\taro\practice> cat memo.txt
hello
PS C:\Users\taro\practice> cd ..
PS C:\Users\taro>

プロンプトが C:\Users\taro に戻れば完了です。

2-5. 便利な使い方

操作効果
Tab キー途中まで打った名前を、自動で補ってくれる。cd pra と打って Tab を押すと cd practice になる。打ち間違いも減る
↑ キー前に打ったコマンドを呼び出す。何度も押すと、さらに前のコマンドが出る
cls画面をきれいにする（ファイルやフォルダは消えない）
エラーが出ても慌てない 間違えたコマンドを打つと、赤い文字でエラーが出ます。ほとんどの場合、何も壊れていません。「打ち間違い（スペース、全角、名前の綴り）」をまず疑い、↑ キーで前のコマンドを呼び出して直してみてください。

2-6. 安全のために：消すコマンドは、まだ使わない

この章で使ったコマンドは、すべて「見る・移動する・作る」だけで、何かを失うことはありません。

ファイルやフォルダを消す rm（Remove-Item）というコマンドもありますが、エクスプローラーの「ごみ箱」と違い、消したものは元に戻せません。間違えると、大切なファイルが戻らなくなります。この教材では、必要になる時まで使いません。

やりたいことエクスプローラーコマンド注意
コピーCtrl+C → Ctrl+Vcp同じ名前があると上書きされる
移動・名前変更ドラッグ、F2mv同じ名前があると上書きされる
削除Delete（ごみ箱へ）rm元に戻せない

確認クイズ

Q1. 今いるフォルダを確認するコマンドは？

pwd。プロンプト（行の先頭）にも、現在地が表示されている。

Q2. C:\Users\taro\practice にいるとき、C:\Users\taro に戻るコマンドは？

cd ..。（cd と .. の間に、半角スペースを入れる）

Q3. ターミナルで作ったフォルダは、エクスプローラーで見えますか？

見える。ターミナルもエクスプローラーも、同じファイルとフォルダを操作しているため。

Q4. cd practice が動かないとき、まず疑うことは？

打ち間違い。cd と practice の間の半角スペース、全角の文字や記号が混ざっていないか、practice フォルダがある場所（現在地）にいるか、を確認する。
