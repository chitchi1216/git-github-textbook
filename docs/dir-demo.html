動かして学ぶ：ディレクトリと現在地

この補足でできるようになること
  • 「ディレクトリ」が、エクスプローラーの「フォルダ」と同じものだと分かる
  • フォルダの「木」の上で、今どこにいるかを思い描ける
  • pwd・ls・cd で、現在地がどう動くか説明できる

1. ディレクトリ ＝ フォルダ

ディレクトリは、エクスプローラーのフォルダと、同じものです。ターミナルの世界では、フォルダのことを「ディレクトリ」と呼びます（PowerShell の ls の表示にも、「Directory（ディレクトリ）」と出てきます）。

フォルダは、フォルダの中にフォルダを入れられるので、全体は木を逆さにしたような形になります。ターミナルは、この木のどこか1か所に立っていると考えてください。その場所が現在地です。

  • pwd ＝ 「今、どこ？」と聞く
  • ls ＝ 「この部屋に、何がある？」と聞く
  • cd ＝ 「別の部屋へ、移動する」

3. ミッションに挑戦

  
    
    
  1. cd practice で中に入り、ls で何があるか見る。pwd で現在地も確かめる。
    2. 
    
  2. cd .. を2回押して、C:\ まで戻る。木の上で、現在地はどう動いた？
    3. 
    
  3. cd C:\Users\taro で移動してから、cd practice を押す。エラーになります。なぜでしょう？
    4. 
    
  4. 続けて cd C:\work\practice を押す。今度は、成功します。さっきとの違いは？
    5. 
  

  

    3 と 4 の答え
    
practice は相対パスなので、「今いる場所の中の practice」を探します。C:\Users\taro の中には practice がないので、エラーになります。

    
C:\work\practice は絶対パス（住所）です。ドライブ名から全部書いてあるので、今どこにいても同じ場所に行けます。

  


  

    まとめ
    ターミナルは、いつもフォルダの木の「どこか1か所」に立っています。コマンドは今いる場所に対して実行されます。困ったら、pwd で場所を確かめましょう。Git も、「今いるフォルダ」の記録を管理する道具です。
