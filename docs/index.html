Git と GitHub 入門

パソコンの基本から始めて、4人でチーム開発ができるようになるための教材です。環境は Windows 11 の PowerShell と VS Code を使います。

この教材の進め方 基本は一人で読み進める自習です。月に1回みんなで集まり、各章の「話し合おう」を題材にディスカッションします。わからないところはそのままにせず、集まりで質問してください。
