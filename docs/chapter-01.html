パソコンの仕組み

この章でできるようになること
  • ファイルとフォルダの階層構造と「パス」を読める
  • OS とアプリの関係、クラウドとは何かが分かる

普段エクスプローラーを使っていれば、すでにファイルとフォルダの操作はできています。この章では、その裏側で何が起きているかを整理します。次の第2章で使うターミナルを理解するための土台になります。

1-1. ファイルとフォルダは「木」の形をしている

パソコンの中のファイルは、フォルダの中にフォルダがある、という入れ子の構造で整理されています。この構造を図にすると、木を逆さにした形になります。

「デスクトップ」「ドキュメント」の場所は人によって違う OneDrive でバックアップを有効にしていると、デスクトップやドキュメントの実体が C:\Users\taro\OneDrive\… の中に移っていることがあります。この教材の演習では、場所の違いに左右されないよう、自分のユーザーフォルダ（C:\Users\taro）の直下を使います。

1-2. パス：ファイルの住所

ファイルやフォルダの場所を文字で表したものをパスといいます。住所と同じで、一番大きな単位から順にたどります。

C:\Users\taro\Documents\memo.txt
部分意味
C:Cドライブ（一番上）
UsersCドライブの中の Users フォルダ
taroその中の taro さんのフォルダ
Documentsその中の Documents フォルダ
memo.txt最後がファイル。.txt が拡張子

「¥」と「\」は同じ文字（混乱しやすいところ）

パスの区切りに使う「\」は、バックスラッシュという記号です。日本語のパソコンでは、フォントによって「¥」（円記号）の形で表示されます。見た目が違うだけで、中身は同じ文字です。キーボードで「¥」と書かれたキーを押すと入力できます。

見た目名前パスやコマンドで使える？
\バックスラッシュ使える
¥円記号（半角）。\ と同じ文字使える
￥円記号（全角）。別の文字使えない
全角の「￥」が入ってしまうとき 日本語入力がオン（「あ」の状態）だと、¥ キーで全角の「￥」が入ることがあります。コマンドやパスを打つときは、半角/全角キーを押して、入力モードを「A」（半角英数）にしてから打ってください。画面右下の入力モード表示で確認できます。
☕ コーヒーブレイク：なぜ「¥」と「\」は同じ文字なの？（読み飛ばしてOK）

これは、パソコンが文字を番号で覚えていることから始まる話です。

  1. 文字には番号がある。パソコンは「A は 65番」のように、文字を番号で覚えています。この番号表を文字コードといいます。
  2. アメリカの表（ASCII）では、92番は「\」。世界で最初に広まった英語圏の表です。
  3. 日本の表（JIS）では、92番を「¥」にした。当時は「国ごとに、いくつかの記号を入れ替えてよい」という決まりがありました。日本語の文書には円記号が欲しいので、92番を「¥」にした、とされています。韓国は同じ92番を「₩」（ウォン）にしました。
  4. 1983年ごろ、MS-DOS がフォルダの区切りに92番を採用した。日本で売られた DOS では、92番が「¥」で表示されたので、日本では C:¥DOS¥… と見えました。同じ92番が、アメリカでは C:\DOS\… と見えていたのです。
  5. 今の Windows でも、番号は同じ92番。変わったのは、画面に描くときのフォントです。古くからある日本語向けのフォントは92番を「¥」の形で描き、新しいフォントや英語圏のフォントは「\」の形で描きます。だから、画面によって見た目が違います。
  6. 全角の「￥」は、92番とは別の番号の文字。だから、パスでは使えないのです。

おまけ（豆知識）

  • 昔の日本語の文字コード（Shift_JIS）では、「ソ」「表」「能」などの漢字・カタカナの2番目の部分がたまたま92番でした。そのため、これらの文字を含むファイル名やプログラムが、古いソフトで壊れる不具合がありました。「5C問題」と呼ばれています。
  • なお、この不具合は今ではほとんど起きません。今の Windows やブラウザは、Unicode という新しい表で文字を扱っているためです。

※ 年代や細かい経緯には諸説あります。詳しく知りたい人は「JIS X 0201」「ISO 646」「5C問題」で調べてみてください。

エクスプローラーで確認してみよう エクスプローラーの上のアドレスバーの空いている場所をクリックすると、今開いているフォルダのパスが文字で表示されます。いろいろなフォルダでやってみてください。

拡張子とは

ファイル名の最後の .txt や .docx が拡張子です。「このファイルは何の種類か」をパソコンに伝える目印です。初期設定では非表示のことがあります。エクスプローラーの「表示」メニューから「ファイル名拡張子」にチェックを入れて、表示しておきましょう。

1-3. OS とアプリ

OS（オペレーティングシステム）は、パソコン全体の管理役です。この教材では Windows 11 のことです。画面の表示、ファイルの管理、キーボードやマウスの受付などを担当します。

アプリ（Word、ブラウザ、VS Code など）は、OS にお願いしてファイルを読み書きしたり、画面に表示したりして動きます。エクスプローラーも、ファイルを見せてくれるアプリの一つです。

1-4. プログラムとソースコード

アプリの正体はプログラムです。プログラムは、人間が書いた「ソースコード」から作られます。そして、ソースコードは、ただのテキストファイルです。メモ帳で開ける文字の並びで、特別なものではありません。

Git が記録するのは、主にこのソースコードのようなテキストファイルの変更履歴です。「文字ファイルの変更を記録する道具」と覚えておいてください。

1-5. クラウドとは

「クラウド」という言葉は雲のようで、つかみにくいかもしれません。実際は、インターネットの向こうにある、誰かの大きなパソコン（サーバー）のことです。

GitHub も、その一つです。自分のパソコンにあるファイルの記録を、GitHub のサーバーに置くことで、離れた場所にいる4人が同じ記録を見られるようになります。

確認クイズ

Q1. C:\Users\hanako\Desktop\plan.md で、ファイルはどれですか？

最後の plan.md。それより前の Users、hanako、Desktop はフォルダ。

Q2. GitHub にあるものはどこに保存されていますか？

インターネットの向こうにある、GitHub のサーバー。
