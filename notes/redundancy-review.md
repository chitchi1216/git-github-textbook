## 優先度：低（わざと繰り返しているので、残してよいもの）

- Git と GitHub の違い（第0章 0-7 → 第1章 1-5 → 第4章 4-1）：章が進むごとに詳しくなる、段階的な説明。
- pull = fetch + merge（第4章の 💡 → 第6章 6-4）：伏線と、その答え。
- 確認クイズが本文を繰り返していること：復習なので、当然。
- `--force` を使わない（第4章のボックス・Q5、第5章の reset）：危険なことなので、繰り返す価値がある。
- AI と Git（第0章 0-2 のボックス → 第5章のコーヒーブレイク）：予告と本編の関係。第0章のほうは1文に縮めてもよい。

## 進め方の案

いちばん効果が大きいのは、#1〜#4（同じ注意書きを、本体の1か所にまとめる）と #8（目次ページと第0章の重なり）。この2つから手をつけるのがおすすめ。ほかの章の注意書きは、本体の1か所へのリンクにすれば、内容を落とさずに短くできる。
